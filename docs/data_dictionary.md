# Data Dictionary

> **All data in this project is synthetic**, generated by `src/generate_data.py`
> with fixed random seeds. Every record carries `is_synthetic = True`. The
> datasets mimic the structure of real bank-marketing and auto-insurance
> portfolios but contain no real customer or policyholder information.

## Dataset A — `marketing_customers` (45,000 rows)

One row per bank customer in the modeled campaign population.

| Column | Type | Description |
|---|---|---|
| `customer_id` | int32 | Unique customer identifier (1–45,000) |
| `age` | float32 | Customer age in years (18–80) |
| `income_k` | float32 | Estimated annual income, USD thousands |
| `tenure_months` | int32 | Months since account opening (1–240) |
| `avg_balance` | float32 | Average deposit balance, USD |
| `num_products` | int8 | Number of bank products held (1–5) |
| `prior_response` | int8 | Responded to a previous campaign (0/1) |
| `region` | category | Customer region: Northeast / Midwest / South / West |
| `email_consent` | int8 | Reachable by email (0/1) |
| `sms_consent` | int8 | Reachable by SMS (0/1) |
| `phone_consent` | int8 | Reachable by phone; skews toward tenured, previously-responsive customers (0/1) |
| `mail_reachable` | int8 | Reachable by direct mail (0/1) |
| `treatment` | int8 | Randomized campaign exposure flag for uplift modeling (0 = control, 1 = treated) |
| `response` | int8 | Campaign response indicator — the modeling target (0/1) |
| `is_synthetic` | bool | Always `True`; marks the record as synthetic |

Derived / modeled fields (not stored in the base table):

| Field | Description |
|---|---|
| `uplift_score` | Two-model uplift: P(response\|treated) − P(response\|control) |
| `pred_response` | Predicted response probability from the treated-population model |
| `segment` | k-means cluster assignment (5 segments) |

## Dataset B — `auto_policies` (595,000 rows)

One row per auto insurance policy.

| Column | Type | Description |
|---|---|---|
| `policy_id` | int32 | Unique policy identifier (1–595,000) |
| `driver_age` | float32 | Primary driver age in years |
| `vehicle_age` | float32 | Vehicle age in years (0–25) |
| `vehicle_type` | category | sedan / suv / truck / sports |
| `territory` | category | Rating territory: urban / suburban / rural |
| `annual_miles` | float32 | Estimated annual mileage |
| `prior_claims` | int8 | Claims in the prior 3 years (0–4) |
| `credit_band` | category | Insurance credit band: excellent / good / fair / poor |
| `coverage_tier` | category | basic / standard / premium |
| `premium` | float32 | Earned premium for the policy term, USD |
| `claim` | int8 | Claim occurrence indicator — the modeling target (0/1) |
| `severity` | float32 | Incurred claim amount, USD (0 when `claim = 0`) |
| `is_synthetic` | bool | Always `True`; marks the record as synthetic |

Derived / modeled fields:

| Field | Description |
|---|---|
| `claim_score` | Predicted claim probability from the gradient-boosting model |
| `risk_tier` | Quintile of `claim_score` on the test set (1 = lowest risk … 5 = highest) |
